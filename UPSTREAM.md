# Upstream source

This standalone fork starts from Weston **15.0.1**, matching the installed
Weston runtime at initial setup.

- Project: https://gitlab.freedesktop.org/wayland/weston
- Release: https://gitlab.freedesktop.org/wayland/weston/-/releases/15.0.1
- Archive: https://gitlab.freedesktop.org/wayland/weston/-/releases/15.0.1/downloads/weston-15.0.1.tar.xz
- Archive SHA-256: `551d039bfb0c837ba5a4d027cdb8ee16bded0eedb789821f8025d8a64b791f6d`

Imported files:

- `kiosk-shell/kiosk-shell.c`
- `kiosk-shell/kiosk-shell.h`
- `kiosk-shell/kiosk-shell-grab.c`
- `kiosk-shell/kiosk-shell-grab.h`
- `shared/helpers.h`
- `COPYING`

The only initial shell source change is replacing the in-tree include
`frontend/weston.h` with the installed public plugin header `<weston.h>`.
The standalone Meson files replace the upstream in-tree build integration.
The input-method protocol generated by
the upstream build is unused by these source files and is not generated here.

Subsequent fork changes add the layer-shell server in `kiosk-shell/layer-shell.c`
and connect kiosk sizing/positioning to per-output usable areas. Layer-shell
layers, lifecycle and focus are integrated into the original shell.

`protocols/wlr-layer-shell-unstable-v1.xml` was imported from the installed
`wlr-protocols` package (`pkg-config` version 1.0), with its original copyright
and license intact. It describes protocol version 5; the server advertises
version 4. Source project: https://gitlab.freedesktop.org/wlroots/wlr-protocols
XML SHA-256: `87e0b9c837aecd6977f76f3c47d73088b7159871f5d979dc1840f6cadb5e2ed8`.

Keep the original copyright and license notices when modifying these files.
When updating upstream, compare these files against the pinned release, then
update the dependency major version and verify loading with that Weston runtime.
